- src/cookie.ts
	- A behavior component that creates a clickable object with visual feedback effects, specifically scaling down to 80% and reducing opacity to 50% for 150ms when clicked. Upon left-click, it sends a network message to the server with player information using the "@cookie/click" event, making it suitable for implementing interactive elements that need both visual feedback and server communication.
- src/global-stats.ts
	- A global statistics manager that tracks and synchronizes player click counts across the game, maintaining a persistent leaderboard system using key-value storage. Implements server-side click validation, player join handling, and real-time leaderboard updates, with automatic data persistence for total clicks and individual player statistics. Features synced values for cross-client consistency and uses Zod schema validation for network message safety.
- src/leaderboard-ui.ts
	- A leaderboard UI component that displays and automatically updates player rankings based on click counts. Implements a client-side behavior that creates a floating, styled leaderboard window and synchronizes with a global stats system through the `GlobalStats` behavior, sorting players by their click counts and highlighting the top player in green. The component uses the `@syncedValue` decorator for entity synchronization and maintains real-time updates through a value change listener system.
- src/total-clicks-ui.ts
	- A UI behavior that displays and updates a total clicks counter in the bottom-right corner of the game screen, styled as a modern floating panel. Implements real-time synchronization with a GlobalStats entity through a synced value adapter, updating the display whenever the totalClicks value changes, and only operates on the client side of the game.
